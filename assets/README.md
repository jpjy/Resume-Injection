# Font required to regenerate injected PDFs

The archived experiment used `LiberationSans-Regular.ttf` version 1.07.4, SHA-256 `f8ace1f892b2bd9dc1792ba7f097fa7588f84fed48321480e04de5390828221f`.

Place that exact file at `assets/LiberationSans-Regular.ttf` before running `scripts/generate_reconstructed_injections.py`. Version 1.07.4 is available from the [Liberation Fonts upstream release](https://github.com/liberationfonts/liberation-fonts/releases) or compatible package archives.
